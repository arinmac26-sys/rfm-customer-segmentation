# RFM Customer Segmentation — Portfolio Report

## Executive Summary

This project applies RFM analysis to convert customer transaction history into actionable customer segments.

## Analytical Deliverables

- Data quality assessment
- Data cleaning and validation
- Customer-transaction integration
- Recency, Frequency and Monetary calculation
- Quintile-based RFM scoring
- Business segmentation
- Segment-level customer and revenue analysis
- Visual analysis
- Pareto analysis
- SQL analytical model
- Business recommendations

## Portfolio Positioning

The project demonstrates an end-to-end analytics workflow suitable for customer analytics, CRM, retention, lifecycle marketing and customer value analysis.
